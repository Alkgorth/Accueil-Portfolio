Esportify

Projet réalisé dans le cadre de ma formation : une application web de gestion de tournois d'Esport. J'ai conçu et développé l'application de A à Z, en front j'ai utilisé HTML / CSS et JavaScript, et en backend j'ai utilisé PHP, MySQL pour la base de données relationnelle MongoDB pour le non relationnelle et Docker pour le déploiement sur mon VPS. L'application permet aux utilisateurs de créer des tournois, de gérer les inscriptions et de consulter les résultats en temps réel. Ce projet m'a permis de mettre en pratique mes compétences fullstack et de comprendre les enjeux du développement d'une application complète, du code à la mise en production.
